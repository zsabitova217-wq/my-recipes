git restore - отменить правку до коммита
git checkout хеш - посмотреть версию проекта на тот момет, хеш используется как идентификатор
HEAD detached - находимся на коммите, не на ветке
git revert - отменить изменение коммита
git switch -c - создать новую ветку и перейти в нее
git merge - влить изменения из этой ветки в ту которой находимся
fast-forward - объединить ветки, передвинуть ярлычок вперед
git branch -d удалить ветку после слияния

Конфликт слияния в Git - конфликт возникает если внесены были изменения в один и тот же файл, тогда программа сама подсветит об этом разработчику и он сам выберет какие изменения оставляем.

Merge request - запрос на объединение изменений из одной ветки в другую
